# 看護師国試 徹底マスター

看護師国家試験の学習アプリ（iPad・スマホ対応のWebアプリ／PWA）。
苦手分野を3回連続正解するまで徹底的に出題し、間違えた問題は図解と音声で解説します。

## 使い方（iPad）
1. ブラウザ（Safari・Chrome・Edge など）でこのアプリのページを開く
2. iPad/iPhone：共有ボタン →「ホーム画面に追加」
   Android：︙メニュー →「アプリをインストール」／パソコン：アドレスバーのインストールアイコン
3. ホーム画面のアイコンから起動（一度開けばオフラインでも使えます）
※追加しなくても、ブラウザのままで使えます。

学習記録は各端末に保存されます。機種変更時は「記録」タブのバックアップを使ってください。

## 出典
- 合格基準・試験日：厚生労働省「看護師国家試験」発表資料
- 過去問の分類・掲載数：看護roo!（© QUICK CO.,LTD.）。問題文・解説は転載せず、リンク先で閲覧します。
- 収録問題・解説・図解は本アプリのオリジナルです。
